# cn-broker-api 依赖。刻意只有四项——这个服务的价值在于把「本机券商客户端」这摊脏活
# 关在一个进程里，它自己不该再长出一个依赖树。
#
# ⚠️ 绝不引入母项目那套（pandas / sqlalchemy / psycopg / dishka）：本服务不碰数据库、
#    不做任何分析，只把请求翻译成对客户端的调用。引进来就等于把「轻量」变成一句空话。

# Web 框架：与母项目同一套写法（单人维护，少一套idiom就少一处出错）
Flask~=3.1
# WSGI 服务器。开发服务器不适合长跑；waitress 是纯 Python、Windows 上稳
waitress~=3.0

# 窗口位图分析：按颜色找【登录】那块红、量密码框星号总宽
pillow~=12.0

# 客户端那条 JSON-RPC 通道。⭐ 这一项是**为了不手抄**才加的：搬过来的
# `drivers/tdxquant/client.py` 里那段传输层是真机验证过的（「传输层失败与业务失败必须
# 分开」那条判据就长在里头），改写成标准库 urllib 等于把验证结果作废。
# 换句话说，这里付一个依赖，买的是「那 585 行一个字符没动」。
requests~=2.32
